# MVP (Minimum Viable Product)

The first public version will include:

✅ User Registration

✅ Login

✅ Communities

✅ Create Posts

✅ Questions

✅ Discussions

✅ News Posts

✅ Comments

✅ Voting

✅ Search

✅ Profiles

✅ Moderation

Everything else will be added gradually after launch.

---

# Guiding Principle

Every feature must answer one question:

Does this help users share knowledge, solve problems, or strengthen the community?

If not, it should not be included.
